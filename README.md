# 🍪 FoodyFortune

FoodyFortune is a simple interactive mini-game built with React. Click and break food items to discover motivational messages hidden inside!

🎮 **Live Demo:** https://foodyfortune.netlify.app/

## ✨ About

FoodyFortune is a small web game designed to create a fun and satisfying experience through simple interactions.

Players click on food items to break them open and reveal a motivational message. The project focuses on responsive user interactions, React state management, and a simple, intuitive UI.

## 🛠 Tech Stack

* React
* JavaScript
* Tailwind CSS
* Netlify

## 🎮 How to Play

1. Choose a food item.
2. Click to break it.
3. Reveal the message hidden inside.
4. Keep playing to discover more messages!

## 💡 Development

FoodyFortune was developed as a personal project to practice building interactive interfaces with React.

The project makes use of component-based design and React state management to handle user interactions and game progression.
